This HTML file is a UI review of a series of web pages, produced by a human reviewer using a browser extension. Each comment is the reviewer describing an incorrect style or behavior found on a specific page. It is intended to be read by a developer or AI coding agent and acted on: locate the referenced page, read the comment as an instruction, and make the code change it describes, using the attached screenshot (when present) to see exactly what the reviewer is pointing at.

How to parse this document:

- Each reviewed page is a div with class 'page-section', containing a paragraph with class 'page-url' that wraps a link. That link's href is the exact URL that was reviewed (its visible text may omit query parameters for readability, but the href always has the full URL, params included).
- Each individual piece of feedback is a div with class 'comment' inside that page's page-section. Its unique id is the data-comment-id attribute on that div (format CM-<number>, e.g. CM-3), also shown as visible text in a paragraph with class 'comment-id' inside the comment.
- The reviewer's actual feedback is the text inside that comment's element with class 'comment-text' (line breaks inside it are real br tags).
- If the comment has a screenshot, its thumbnail is an img with class 'shot-thumb' inside that comment's div with class 'comment-shots'. The same image at full resolution is also embedded in a matching lightbox element elsewhere in the document (an anchor with class 'lightbox' wrapping an img) - the thumbnail's link href and the lightbox element's id are the same value (e.g. #shot-2), which is how the two are paired. Some screenshots have freehand cyan-colored markings drawn directly onto the image by the reviewer, highlighting the specific element or area the comment is about - treat that cyan drawing as a pointer to what to look at, not as part of the page's actual design.
- This whole session (i.e. every page and comment in this file) has one shared unique id, in a meta tag named alan-review-session-id in this document's head. Combine that session id with a comment's CM-<number> id to get a globally unique identifier for that single piece of feedback, since CM-<number> alone only counts up within one session.
