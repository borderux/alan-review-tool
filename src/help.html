Using ALAN Review Tool

Click the toolbar icon on any site to open or close this panel. Opening the panel pushes the page over to make room - it never covers content up.

Comments and screenshots

+ New comment starts a text comment on the current page. + New screenshot lets you drag a rectangle anywhere on the page to capture that region - drag near a screen edge and release outside the browser window works fine too.

Click a comment's screenshot to open it full-size. While it's open, you can draw directly on the image (cyan, freehand) to point at the specific thing you mean - Clear Annotations wipes the current drawing, and clicking outside the image to dismiss it permanently bakes whatever's drawn into the screenshot. Once dismissed, previous annotations can't be removed.

Copy a comment (with your browser's normal copy shortcut) and paste it to duplicate it, screenshot included.

Sessions

Every comment and screenshot you add - on any page, any site - belongs to one review session. Fill in your name, email, and any session-level notes in the fields above; those persist across every page you visit during the review.

Clear Session deletes every comment across every page in the current session. This can't be undone.

The report

Download report exports everything in the current session as a single HTML file - one section per page, with a table of contents, and each screenshot as a click-to-enlarge thumbnail. It's a plain file with no JavaScript in it at all, so it opens anywhere.

Resizing

Drag the thin strip at the very left edge of the panel to resize it - the width you choose is remembered next time you open the panel.
