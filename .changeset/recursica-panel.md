Rename the extension to Snippy and rebuild its review panel on the Recursica design system (React, TypeScript, Vite): light and dark mode following the operating system; a single comment list with one Add menu in the header (Comment, Screenshot, Element), each comment numbered 1, 2, 3; screenshot comments with Add annotations and a pen color dropdown with six colors; a menu per comment for Duplicate and Delete; confirmation before any delete or Start over; a download dialog for the reviewer name, email and session details; and a failed save reported as a message. Stored data moves to new storage keys automatically. Firefox: Snippy has a new add-on id, replacing the Alan Review Tool's, so Firefox installs Snippy as a new add-on and data stored by the Alan Review Tool is not carried over. The extension now requests the unlimitedStorage permission so long sessions with screenshots do not hit the storage quota.
