Rename the extension to Snippy and rebuild its review panel on the Recursica design system (React, TypeScript, Vite): light and dark mode following the operating system; a single list of comment cards with one Add menu in the header (Comment, Screenshot, Element), numbered 1 to N with no gaps (deleting a comment renumbers the rest); two checkboxes at the end of the comment list to show only this page's comments (or every page's, grouped by page) and to show screenshot thumbnails, both remembered; a wider panel (400 to 720 px, 440 by default); screenshot comments with Add annotations and a pen color dropdown with six colors; Duplicate and Delete buttons on each comment; confirmation before anything that can't be undone, including discarding an unsaved drawing; page headings and a link on every report comment back to its page (and to the element, when it has a simple unique id); a Download report button showing the total count, with a dialog for the reviewer name, email and session details; a failed save reported as a message; and, if saved data can't be read, a panel that still opens with a message and Add turned off. Stored data moves to new storage keys automatically. Firefox: Snippy has a new add-on id, replacing the Alan Review Tool's, so Firefox installs Snippy as a new add-on and data stored by the Alan Review Tool is not carried over. The extension now requests the unlimitedStorage permission so long sessions with screenshots do not hit the storage quota.
