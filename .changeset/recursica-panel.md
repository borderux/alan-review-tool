Rename the extension to Tagger and rebuild its review panel on the Recursica design system (React, TypeScript, Vite): light and dark mode following the operating system; tabs for Comments, Reviewer and Help; a New comment field where Enter adds a numbered comment; screenshot comments with Add annotations and a choice of six pen colors; a menu per comment for Duplicate and Delete; confirmation before any delete or Start over; and a failed save reported as a message. Stored data moves to new storage keys automatically. Firefox: the add-on id changes to tagger@borderux.com, so Firefox installs Tagger as a new add-on and data stored by the old version is not carried over. The extension now requests the unlimitedStorage permission so long sessions with screenshots do not hit the storage quota.
